# SCIC - Sistema de Comunicação Interplanetária da Colônia
**Missão Aurora Siger - Marte (FIAP)**

Este repositório contém a solução do **SCIC (Sistema de Comunicação Interplanetária da Colônia)**, desenvolvida para a Missão Aurora Siger em Marte. O sistema realiza a gestão de telemetria, análise numérica de erros, previsão de latência via Machine Learning, priorização de alertas com Min-Heap, busca por prefixo com Árvore Trie e diagnóstico elétrico operacional.
